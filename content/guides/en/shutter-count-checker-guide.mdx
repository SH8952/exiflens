When you're buying a used camera, the seller's word on "barely used" only goes so far. The shutter count — the total number of times the shutter has fired over the camera's life — is the closest thing photography has to an odometer reading. Most shutter mechanisms are rated for a certain number of actuations (often 100,000–400,000 depending on the body's class) before wear makes servicing more likely, so a body with a low count relative to its rated life is a meaningfully safer buy than one that's already deep into its expected lifespan.

Our [Shutter Count Checker](/tools/shutter-count-checker) reads this value directly out of a NEF or JPEG file, entirely in your browser — no upload, no account, nothing leaves your device.

## Where this number actually lives

Ordinary EXIF fields (aperture, shutter speed, ISO, lens) are standardized across every camera brand, which is why any EXIF viewer can read them. Shutter count isn't part of that standard set — each manufacturer stores it (or doesn't) inside a proprietary block called the MakerNote, and the exact byte layout differs by brand and often by model generation. That's why so many "EXIF viewer" tools show you everything except this one number: they only parse the standardized fields, not the manufacturer-specific ones.

## Why Nikon first — and now two Canon bodies

Nikon documents its `ShutterCount` field as a plain, unencrypted 32-bit number inside its MakerNote — a detail confirmed by multiple independent, publicly documented sources, not just Nikon's own tools. We verified our implementation against real Nikon camera files and it matches exactly.

Canon is a very different story: there's no single formula. Canon stores this value at a different byte offset inside a per-model binary block for practically every camera family, and each offset has to be individually discovered and published before any tool — ours included — can read it. As of this writing, that offset is only publicly documented for the EOS R5, EOS R6, EOS R6 Mark II, EOS R8, and EOS R50 — so those five Canon bodies (CR3 files only) are what this tool currently supports. Every other Canon camera, including newer EOS R models, still shows as unsupported — not because it can't ever be done, but because nobody has published where the value lives in those models yet. If you shoot one of the two supported Canon bodies, note that this support is based on published camera data rather than tested against every individual unit and firmware version.

Sony, Fujifilm, Olympus, Panasonic, and Pentax are further behind for different reasons in each case — some store an equivalent value in a way that shifts by model generation and firmware, some genuinely never write it to the file at all. We're continuing to expand coverage rather than treating this list as final.

## Using it before you buy

If you're buying secondhand, ask the seller for a straight-out-of-camera JPEG or NEF (not a screenshot, and not a file that's been re-saved by editing software, which typically strips this metadata) and run it through the checker yourself. Compare the count against the body's rated shutter life for its class, and weigh that alongside the visible cosmetic condition — the two together tell you far more than either one alone.
