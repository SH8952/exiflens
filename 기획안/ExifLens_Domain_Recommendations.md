# [ExifLens] 글로벌 웹 서비스 도메인 네이밍 추천 & 등록 가이드

---

## 1. 서비스 개요 및 타겟
- **서비스 핵심 기능:** 카메라 EXIF 분석 & ND 필터 장노출 계산기 + 15종 EXIF 감성 액자 생성기
- **타겟 유저:** 글로벌 사진작가, 장노출 촬영가, 인스타그램/X 커뮤니티 유저
- **목적:** 구글 검색 최적화(SEO), 신뢰도 확보, 브랜드 각인 및 애드센스 승인률 극대화

---

## 2. 카테고리별 추천 도메인

### A. 브랜드형 도메인 (짧고 기억하기 쉬운 네이밍)
글로벌 커뮤니티(Reddit, X 등)에서 바이럴하기에 가장 적합한 직관적인 브랜드명입니다.

- **ExifLens.com / ExifLens.app** *(최우선 추천: EXIF + 렌즈의 직관적 결합)*
- **ExifFrame.com / ExifFrame.app** *(EXIF + 액자 기능 직관적 강조)*
- **LightND.com / LightND.app** *(빛과 ND 필터 전문 도구 느낌)*
- **ShutterShift.com / ShutterShift.app** *(셔터스피드 변환 및 장노출 느낌)*
- **ExifSnap.com** *(스냅 사진과 EXIF 메타데이터의 경량화된 합성어)*

---

### B. SEO / 기능 중심 도메인 (검색 유입에 유리)
글로벌 유저들이 검색창에 입력하는 주요 키워드(ND Calculator, EXIF Viewer 등)를 직접 포함하여 구글 검색 노출(SEO) 점수를 극대화합니다.

- **ExifCalc.com / ExifCalc.io** *(EXIF + Calculator 결합)*
- **NDFilterCalc.com** *(ND 필터 계산기 검색 키워드 타겟팅)*
- **LongExposureCalc.com** *(장노출 계산기 글로벌 검색 키워드 직접 타겟팅)*
- **ExifMaker.com** *(EXIF 프레임/카드 제작 도구 느낌)*
- **PhotoExifTool.com** *(사진 메타데이터 종합 툴 느낌)*

---

### C. 감성 / 작가 타겟형 도메인 (EXIF 액자 기능 강조)
사진작가나 SNS 유저들에게 "내 사진을 꾸미고 공유하는 감성 도구"로 인지시키기 좋은 네이밍입니다.

- **ShotOnCard.com** *("Shot on [카메라]" 프레임 카드 제작 도구)*
- **FrameExif.com** *(프레임과 EXIF의 결합)*
- **PhotoFrameLab.com** *(사진 액자 실험실 느낌)*
- **ExifStudio.io** *(전문가용 EXIF 편집/액자 스튜디오 느낌)*

---

## 3. 도메인 구매 팁 & 등록 가이드

1. **최우선 확장자는 `.com`:**
   - 글로벌 유저의 신뢰도 확보 및 구글 애드센스 승인 심사 시 가장 안정적입니다.
2. **차선책 확장자 (TLD):**
   - 원하는 `.com` 도메인이 이미 점유된 경우 **`.app`**, **`.io`**, **`.co`** 순으로 고려합니다.
3. **추천 등록업체 (Registrar):**
   - **Cloudflare Registrar:** 마진 없는 원가 제공으로 연장 비용이 가장 저렴함.
   - **Namecheap / Porkbun:** 해외 결제가 편리하고 직관적인 인터페이스 제공.

## 4. 도메인 구매 후 즉시 진행할 다음 단계 (Next Steps)
1. **Vercel Custom Domain 연동:** Vercel 대시보드에서 구매한 도메인 DNS 레코드(A Record/CNAME) 연결
2. **Google Search Console 등록:** 루트 도메인 추가 후 `sitemap.xml` 및 `robots.txt` 제출
3. **애드센스 신청:** 루트 도메인 주소로 구글 애드센스 사이트 제출
